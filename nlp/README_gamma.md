## What this does

Replaces the MiniLM (384-dim) text encoder used in Alpha/Beta with SigLIP
(`google/siglip-base-patch16-224`), which jointly encodes text and images in
the same space. This is Gamma's core contribution: the agent gets pre-aligned
text-vision features so PPO doesn't have to learn the translation from scratch.

**Input:** instruction string + object crop image  
**Output:** `{"vision": (768,), "nlp": (768,), "similarity": float}`

The similarity scalar can be used as an optional reward bonus:
`reward += 0.1 * similarity`

## How the RL team uses this

```python
from gamma_pipeline import load_siglip, gamma_encode
import numpy as np

# Load once at startup
model, processor, device = load_siglip()
cache = np.load("embeddings_gamma_768.npy", allow_pickle=True)  # or build_embedding_cache()

# Each RL step
result = gamma_encode(instruction, image_crop, model, processor, device, embedding_cache=cache)
# result["vision"]     → (768,) vision features
# result["nlp"]        → (768,) text features
# result["similarity"] → float, use as reward bonus if ablating
```

## Differences from Alpha/Beta NLP

|                        | Alpha/Beta       | Gamma                |
| ---------------------- | ---------------- | -------------------- |
| Text encoder           | all-MiniLM-L6-v2 | SigLIP text branch   |
| Text dim               | 384              | 768                  |
| Vision encoder         | ResNet18         | SigLIP vision branch |
| Vision dim             | 512              | 768                  |
| Text-vision aligned    | ❌               | ✅                   |
| Separate physics state | ✅ appended      | ❌ not used          |

## Known issues / flags for RL team

- Checkpoint 2 similarity targets (>0.7 match, <0.3 mismatch) assume real object photos.
  Solid color patches will score lower — this is expected. Use real PyBullet renders for
  proper validation.
- Inference on CPU will fail the <10ms target. Must run on Kaggle T4 for that benchmark.
- `embeddings_gamma_768.npy` is generated by `build_embedding_cache()` — commit it to the
  branch after generating on Kaggle so the RL team doesn't have to regenerate.
