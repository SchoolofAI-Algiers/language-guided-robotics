# Language-Guided Robotics

A multi-modal AI system where a robotic agent learns to execute natural language instructions using reinforcement learning, computer vision, and language embeddings.

## Tech Stack
- PyBullet
- Gymnasium
- Stable-Baselines3 (PPO)
- PyTorch
- Sentence-Transformers

## Goal
Train a robot in simulation to understand commands like:
- "pick the red block"
- "move the cube to the table"
- "stack the blue object on the green one"
